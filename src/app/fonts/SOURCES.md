# Sumber dan lisensi font

Font disimpan lokal dan dimuat melalui `next/font/local`. Tidak ada CDN font pada runtime.

## Lexend

- Berkas: `lexend/Lexend-Variable.ttf` (175.756 byte), variable weight 100–900.
- Sumber resmi: https://github.com/google/fonts/blob/main/ofl/lexend/Lexend%5Bwght%5D.ttf
- Proyek: https://github.com/googlefonts/lexend
- Lisensi: SIL Open Font License 1.1; teks lengkap di `lexend/OFL.txt`.

## Atkinson Hyperlegible

- Berkas: `atkinson/AtkinsonHyperlegible-Regular.ttf` (54.348 byte) dan `atkinson/AtkinsonHyperlegible-Bold.ttf` (55.256 byte).
- Sumber resmi: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
- Lisensi: SIL Open Font License 1.1; teks lengkap di `atkinson/OFL.txt`.

Berkas digunakan tanpa modifikasi. Cakupan karakter mengikuti distribusi resmi tersebut, termasuk karakter Latin yang diperlukan Bahasa Indonesia.
